# 招聘网站 RPA 自动化执行系统级最高戒律 (System Rules)

> **适用范围**：当处理招聘后台系统（`admin.jobleap.betaquantity.com`）中“网站列表”与“公司库”的建档、核查、回填或 RPA 任务时，本规则具备**最高优先级宪法效力**，必须无条件绝对服从。

---

## 一、 核心铁律（物理防呆准则）

### 1. 【严禁本末倒置：主战场必须在“网站列表”，由系统自动建档，严禁一开始自行前往公司列表手动建档】
- **禁止提前去公司库建档**：正常来说，国内各招聘平台（国聘、智联、飞书招聘、北森、Moka、大易等）没有公司名称的任务，**必须统一在【网站列表】（`/#/company/index`）点击【配置】弹窗处理，由系统后台保存时自动触发底层建档与外键绑定**！
- **严禁**在一开始就跑去外网盲搜、更**绝对严禁**擅自切到【公司列表】（`/#/company-basic/index`）去点击【新增公司】➜【手动新增】！这是严重的流程越俎代庖事故。
- **唯一合法标准流**：
  1. **第一步（网站列表主战场）**：停留在 `/#/company/index`，动态定位待办行，直接点击行内【配置】；
  2. **第二步（弹窗配置并保存）**：在【配置】弹窗中直接处理信息（国聘直接点确定；其他平台按需填入必要配置），点击【确 定】由系统后台**自动建档落库**；
  3. **第三步（现场核验极速闭环）**：保存后直接读取网站列表当前行，若类型与行业已自动带出，**当前任务立即宣布齐整闭环，全程严禁访问公司列表**；
  4. **第四步（仅按需差量补齐属性）**：只有在网站列表已完成自动建档，但类型或行业仍为空缺时，才前往【公司列表】搜索该公司进行定向差量补充（补类型/行业），补齐后回网站列表刷新，**绝不是去手动创建公司**。
- **特例说明（仅限国外 ATS）**：只有纯境外无国内实体的国外 ATS 企业（如 Greenhouse, Workday 等“境外企业”且系统完全无任何记录），才允许走先公司库建档的特殊兜底流程。国内任务 100% 禁止套用该特例！

### 2. 【严禁手写临时 DOM 写入脚本】
- **绝对禁止**临时编写任何具有页面写入性质的脚本（如 `process_xxx.py`、`fill_xxx.py`、`do_xxx.py` 等）去直接操作 CDP 写入 DOM 或点击弹窗；
- 所有建档与回填操作，**必须统一调用已固化的标准化引擎**：[`rpa_engine.py`](file:///D:/100_Work/101_Program/Proj/XHS/rpa_company_fill/rpa_engine.py)（如 `auto-close`、`configure-site`、`batch-close`）；
- 杜绝一切因临时脚本代码缺陷引发的“经验主义覆盖”与灾难性覆写事故。

### 3. 【严禁下标行号寻行，必须业务主键定位】
- 后台表格处于多爬虫实时并发插入状态，数据行随时向下平移滑动，`nth(i)` 或相对行号在生成的下一毫秒必然失效；
- **绝对禁止**在代码中使用 `tr.nth(i)`、`rows[i]` 进行点击寻行；
- **必须使用不可变业务唯一主键**进行动态过滤：
  * 国聘任务：必须以**国聘唯一纯数字企业ID**（如 `118180342245884090`）过滤寻行；
  * 其他平台任务：必须以**完整页面 URL 核心特征串 / Slug** 进行唯一过滤匹配；
  * 找不到目标主键时立即报错停止，严禁盲目降级点击当前可视行！

### 4. 【国聘任务 100% 物理禁止触碰公司名称输入框】
- **核心业务机理**：国聘网任务（`guopin_v3_spider_task`）在系统初始化时，**本身就已自带官方认证的正确工商全称**；
- **唯一规范流程**：网站列表点击【配置】进入弹窗后，**绝对禁止清空（`fill("")`），绝对禁止重新填入名称**，必须直接点击【确 定】由系统完成自动建档与联动！
- 任何试图清空或篡改国聘公司名称的行为，一律视为严重违规事故！

### 5. 【弹窗内 URL 签名强断言与安全熔断（Invariant Assertion）】
- 弹窗打开后，在执行任何操作前，**必须先读取弹窗内既有的【请求链接】或【网站链接】**；
- 必须与目标唯一 ID 进行字符串精确包含断言校验；
- **熔断机制**：若弹窗内网址与目标不匹配，必须立即抛出异常并点击【取 消】安全退出，**绝对严禁触碰【确 定】保存按钮**！

### 6. 【已有数据 100% 绝对保护（差量录入）】
- **法定门牌地址**：公司库中已有法定详细地址（含街道门牌号）**100% 绝对不碰**，严禁覆盖为单一城市；
- **已有简称**：已有规范简称（非空）**100% 绝对不碰**，绝不进行截断覆盖；
- **复合类型标签**：已有复合类型（如“央企, 上市”）属于业务正确定性，**100% 绝对不碰**，绝不单选重置。

### 7. 【行业定性严格对齐 40 项标准，严禁滥用“综合”】
- 医疗、医药、医院、器械等，必须定性为【生物/医疗/制药】（代码 `5`）；
- 机器人相关企业必须定性为【机器人】（代码 `27`）；
- 云服务/CDN 相关企业必须定性为【云计算】（代码 `29`）；
- 芯片/半导体设计制造必须定性为【硬件/半导体/芯片】（代码 `6`）；
- 农林牧渔企业必须定性为【农林牧渔】（代码 `18`）；
- 只有无可细分多主业集团才允许使用【综合】（代码 `13`）。

### 8. 【51job 爬虫任务依令跳过】
- 凡任务名称为 `five_one_job_spider_task` 的记录，依照用户最高指令一律安全跳过，不做无谓探测与修改。
