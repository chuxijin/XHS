# 校园招聘公告自动核对任务 指导文档

本任务旨在实现飞书《27届校招 Pro 版》与 JobLeap 后台《公司列表》之间招聘公告的一键自动化核验与比对，自动输出每日一致性报告与异常清单。

## 一、 快速开始

### 步骤 1：启动带调试端口的 Chrome 浏览器
在 PowerShell 终端中执行以下命令（不要关闭弹出的浏览器）：
```powershell
Start-Process "C:\Program Files\Google\Chrome\Application\chrome.exe" -ArgumentList "--remote-debugging-port=9222", "--user-data-dir=C:\Users\19396\ChromeDebug"
```

### 步骤 2：打开目标页面
确保 Chrome 浏览器中已打开：
1. **飞书云文档**：《27届校招 Pro 版 - 总表》
2. **JobLeap 后台**：《公司列表》（`http://admin.jobleap.betaquantity.com/#/company-basic/index`，若未打开脚本会自动导航）

### 步骤 3：一键运行比对
```powershell
# 自动核查今天（系统当天日期）并生成报告
.venv\Scripts\python.exe -m job_notice_comparator.main

# 或指定核查特定日期（如 8.25）
.venv\Scripts\python.exe -m job_notice_comparator.main --date 2026-08-25 --output job_notice_comparator/reports/8.25.md
```

## 二、 前置环境准备

- **Python 环境**：项目已配置 Python 3.12 虚拟环境 `.venv/`。
- **Playwright CDP**：通过 Chrome DevTools 端口 `9222` 直连用户浏览器上下文，免去重复登录和 Cookie 授权问题。
- **飞书 SpreadJS 提取**：直读飞书底层数据模型 `window.spreadApp`，高效提取海量行数据与富文本超链接，自动转换 Excel 序列号日期。

## 三、 核心命令与使用方式

### 1. 运行今日核验流水线
```powershell
.venv\Scripts\python.exe -m job_notice_comparator.main
```
- 脚本会自动检测当天系统日期（如 `8.25`）。
- 自动从飞书总表中筛选出今天更新的所有招聘记录。
- 在 JobLeap 公司列表中逐一检索，遍历所有匹配行精准核对公告。
- 自动生成 `job_notice_comparator/reports/{月.日}.md` 报告。

### 2. 补核历史指定日期
```powershell
.venv\Scripts\python.exe -m job_notice_comparator.main --date 2026-08-22 --output job_notice_comparator/reports/8.22.md
```

### 3. 查看命令行参数帮助
```powershell
.venv\Scripts\python.exe -m job_notice_comparator.main --help
```

## 四、 比对与判定规则

### 1. 判定状态定义
| 判定状态 | 含义说明 | 处理建议 |
| :--- | :--- | :--- |
| `MATCH` (✅ 完全一致) | 飞书公告链接与 JobLeap 系统中维护的公告一致 | 无需人工介入 |
| `MISMATCH` (❗ 存在差异) | 飞书公告链接与系统维护的公告不一致 | 查看报告中的差异链接，在 JobLeap 中进行更新 |
| `JOBLEAP_EMPTY` (⚠️ 系统无公告) | JobLeap 已收录该公司，但公告字段为空 | 将飞书公告链接复制并补充至系统 |
| `NOT_FOUND` (❌ 系统未收录) | JobLeap 中未搜索到该名称的公司 | 在 JobLeap 后台新建录入该公司及公告信息 |

### 2. 关键比对特性
1. **多候选记录智能遍历**：
   当搜索简短关键词（如“美的”、“申通快递”、“中国外运”）返回多家分公司/子公司时，系统会**遍历所有返回行**。只要任一行中已维护了与飞书一致的公告，即精准命中该行并判定为一致，避免单行截断造成的误判。
2. **URL 深度规范化与参数清洗**：
   - 自动清洗 `chksm`, `scene`, `click_id`, `sn` 等跟踪参数。
   - 自动兼容微信推文短链 (`/s/...`) 与长链 (`/s?__biz=...`)。
   - 自动去除 URL 末尾的斜杠、协议差异（`http` vs `https`）等格式噪音。

## 六、 常见问题与排查方法

1. **报错 `Target page not found` 或连接超时**：
   - **原因**：Chrome 未开启 `9222` 端口，或未打开对应飞书表格。
   - **解决**：重新以调试参数启动 Chrome，并确保飞书《27届校招 Pro 版》已完整加载。
2. **JobLeap 出现遮罩弹窗导致检索失败**：
   - **机制**：脚本内置了自动关闭弹窗和 JS 驱动填入机制，若遇异常可按键盘 `Esc` 键关闭浏览器遮罩后重试。
3. **飞书日期转换异常**：
   - **机制**：SpreadJS 内部日期为 Excel 序列号（如 `46256` 对应 `2026-08-22`），转换基准日已严格校准为 `1899-12-30`，自动向下兼容字符串日期。
