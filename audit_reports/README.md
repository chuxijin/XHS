# 招聘数据核对与时效性审计规范 (Audit Reports)

本目录用于存放飞书表格中招聘数据的自动化核对报告。核心目标是对表格中 **【公司名称】**、**【招聘公告】**、**【投递链接】** 三者的**统一对应性**、**真实有效性**与**时效性**进行全流程多维核验。

---

## 🎯 核心核对维度与标准

```
      ┌──────────────────────────────┐
      │          公司名称             │
      └──────────────┬───────────────┘
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
┌─────────────────┐     ┌─────────────────┐
│    招聘公告      │ ◄─► │    投递链接      │
│  (官方推文/正文) │     │  (网申系统/官网) │
└─────────────────┘     └─────────────────┘
  【三者统一对应 · 真实有效 · 最新时效】
```

### 1. 【公司名称】与【投递链接】一致性
* **官方域名/系统标识匹配**：核对投递链接域名（如 `*.zhiye.com`、`app.mokahr.com/...`、`*.jobs.feishu.cn`）是否准确指向该企业。
* **工商主体与品牌别名映射**：
  * `智道网联` ↔ `蘑菇车联`（北京智道网联科技有限公司）
  * `得物` ↔ `上海识装信息科技有限公司` / `POIZON`
  * `曹操出行` ↔ `杭州优行科技有限公司`（吉利集团旗下）
  * `喜得国际` ↔ `Cider`
  * `爱笔智能` ↔ `Aibee`
* **连通性与有效性**：排查 HTTP 404、网页已关停、服务器连接中断等死链。

### 2. 【公司名称】与【招聘公告】一致性
* **官方发布主体核验**：微信公众号文章发布主体（账号名称、推文标题、企业认证）是否与公司名称完全对应。
* **推文有效性排查**：排查微信文章是否提示 `账号已迁移`、`内容已被发布者删除` 等失效状态。

### 3. 【招聘公告】与【投递链接】时效性（届数与可投递状态）
* **届数统一性**：
  * 当前有效校招主力批次为 **2027届**（秋招提前批/校园大使）与 **2026届**（秋招/常态校招）。
  * 重点筛查并剔除带有 **24届 / 25届 / 2024春招 / 2025春招** 等历史旧公告。
* **岗位在招状态**：
  * 真实打开投递页面，排查是否带有 `抱歉，该职位已停止招聘`、`该职位招聘已关闭` 等已招满下线提示。

## 🛠️ 自动化核验流程与技术方案

1. **表格底层数据提取**：通过 Chrome 远程调试端口（CDP 9222）连接运行中的飞书表格，直接提取当前工作表所有单元格的文本与绑定的真实超链接（含 Hyperlink 隐藏 URL）。
2. **知识库与静态规则预筛**：结合企业中英文名称、简称、官方招聘系统 Slug 知识库进行快速命中。
3. **浏览器真实动态渲染 (Playwright)**：针对单页应用（SPA）及非直接暴露标题的招聘系统（HotJob、Moka、飞书招聘、北森），在浏览器端动态执行渲染，获取最终 URL、页面 `document.title`、H1 标签及主体文本。
4. **微信文章元数据批量抓取**：多线程并发解析微信推文 `og:title`、正文摘要及账号状态，快速识别届数与迁移状态。
5. **生成结构化审计报告**：按日期输出 Markdown 报告，分类呈现异常项与全量明细表。

## 📋 异常分类与处置建议指南

| 异常类型 | 常见表现 / 状态特征 | 处置建议 |
| :--- | :--- | :--- |
| **🚫 链接失效 / 404** | 页面返回 404，或提示 `当前网页已关停` | 检查并替换为该企业官方招聘官网首页或最新有效职位链接 |
| **🚫 岗位已停止招聘** | 页面提示 `抱歉，该职位已停止招聘` / `职位已关闭` | 将具体的单岗位链接改为该企业**校招岗位列表总入口** |
| **🕒 往期历史届数** | 公告或投递页明确写有 `24届`、`25届`、`2024春招` | 搜索该司官方微信公众号，更新为当季 26/27 届最新推文与链接 |
| **⚠️ 微信账号迁移** | 微信文章打开提示 `该公众号已迁移` | 重新定位该司当前使用的最新官方招聘公众号并替换推文 |
| **ℹ️ 51Job简历直投** | 访问直接跳转至前程无忧应届生简历投递登录页 | 属于正常简历快捷直投通道，主体匹配即可保留 |
